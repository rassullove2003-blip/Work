## Порядок проверки записи (для редактора)

1. Открыть официальную страницу вуза/программы/организации (только домен вуза или регионального агентства).
2. Сверить поля, указать `academic_year`, `source_url`, `verified_at`.
3. Поставить статус «Проверено», снять «Демонстрационная запись», опубликовать.
4. Правила разных учебных лет и регионов не смешивать: для нового года — новая строка в `program_editions` /
   `admission_requirements` / `scholarship_eligibility`.

## Координаты университетов (карта)

Источник: OpenStreetMap через сервис Nominatim (© участники OpenStreetMap, лицензия ODbL), разовая загрузка 25.11.2026.
Точка принималась, только если объект — вуз/кампус и находится в нужном городе (по полю адреса).
`geo_precision = 'city'` — здание вуза однозначно не найдено, точка стоит в центре города (polimi, uniba, unipa, unitn, unimore, unict);
уточнить можно в «Управление → Университеты» (поля «Широта/Долгота»).
Для Android-сборки в магазине понадобится ключ Google Maps (см. документацию react-native-maps); iOS использует Apple Maps без ключа.
