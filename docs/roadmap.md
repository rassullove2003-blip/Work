# План развития

## Этап 1 — MVP (сделано в этой ветке)
Expo-приложение, каталог, поиск, фильтры, вузы, программы, стипендии, избранное, авторизация, профиль,
схема Supabase + RLS, админ-панель, тесты.

## Следующие шаги для завершения Этапа 1
1. Подключить Supabase, применить миграции, назначить администратора — проверить вход, избранное, админку на живом сервере.
2. Редакционно сверить вузы и программы с официальными сайтами, снять пометку «демо».
3. Иконка и сплэш-экран UniItalia, `eas build` для iOS/Android, проверка на реальных устройствах.

## Этап 2 — персональное сопровождение
UniItalia AI (серверный слой через Supabase Edge Function, ключ модели только на сервере, ответы только по проверенной базе),
календарь дедлайнов (EU / non-EU в Италии / non-EU за рубежом) и напоминания за 30/14/7/1 день только по проверенным датам,
трекер поступлений (таблицы уже есть), загрузка документов в приватный bucket, визовый раздел, сравнение до 4 вузов,
форма «Получить помощь с поступлением».

## Этап 3 — развитие
Подписки (RevenueCat с учётом правил App Store/Google Play), расширенные рекомендации, калькулятор бюджета,
карта университетов, казахский/английский/итальянский языки (`apps/mobile/src/i18n`), аналитика.
