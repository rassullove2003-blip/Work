## Задачи по расписанию (Supabase pg_cron)

| Задача | Время (UTC) | Что делает |
|---|---|---|
| `sheets-sync` | 05:35 ежедневно | Вызывает Edge Function `sheets-sync`: для таблиц с включённой автосинхронизацией читает Google Таблицу, проверяет и загружает изменения. При ошибках ничего не меняет и уведомляет администраторов. |
| `deadline-reminders` | 06:05 ежедневно | `send_deadline_reminders()`: напоминания о подписанных сроках и задачах с датой (пороги 30/14/7/3/1/0 дней). |

Edge Function `sheets-sync`: исходник `supabase/functions/sheets-sync/handler.ts`, сборка `bash scripts/build-edge.sh`.
Сборка загружается в bucket `edge-code` (запись — только администратор); входной файл `index.ts` проверяет её SHA-256
перед запуском. После изменения кода: собрать, загрузить новый файл, обновить `BUNDLE`/`SHA256` в `index.ts`, развернуть.
Секрет вызова и адрес проекта хранятся в Supabase Vault (`sheets_sync_secret`, `project_url`), в репозитории их нет.
